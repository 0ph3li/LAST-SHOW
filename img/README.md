# LAST SHOW · photos

every image is a slot: drop a file with the right name into this folder and it appears (`.jpg` or `.png`).

**the film slots hold real stills of each film; the other slots (rooms, street, tram, people) are free unsplash photos.** swap any of them for your own, same filenames. `img/HOME/thumbs/` holds small copies used by the loader and the last-shows list (480px): regenerate them if you change the film or archive photos.
until then each slot shows its filename and what to put there.
